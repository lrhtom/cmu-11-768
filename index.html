01 · 第 1–2 讲

智能体入门与工具调用

What Is an Agent · Tool Use

智能体是什么，由哪几块组成，怎么一圈圈地跑起来。模型怎么学会调用工具：工具描述、调用格式、聊天模板和 MCP。

作业 1
02 · 第 3–4 讲

长上下文、记忆与技能

Long Context · Memory & Skills

上下文越来越长，模型结构和推理系统要怎么改。智能体自己又该怎么管上下文。再讲跨任务的记忆，和按需加载的技能。

作业 1
03 · 第 5 讲

规划与多智能体协作

Planning · Decomposition · Multi-Agent

先想再做。怎么规划，怎么把大任务拆成小任务。多个智能体之间怎么分工、怎么协调。
04 · 第 6、7、10 讲

领域智能体：编程、操作电脑、深度研究

Coding · Computer Use · Deep Research

三类最成熟的智能体各自怎么做。编程智能体写代码修 bug。电脑操作智能体看屏幕点鼠标。深度研究智能体上网查资料写报告。

作业 1、2
05 · 第 8–9 讲

训练（上）：SFT 与强化学习基础

Training: SFT · RL Basics

怎么用轨迹数据做监督微调，让模型学会当智能体。再讲强化学习的基本概念：策略、奖励、策略梯度。最后看它用在智能体上的样子。

作业 3
06 · 第 11–12 讲

训练（下）：进阶 RL 算法与 RL 系统

Training: Advanced RL · RL Systems

智能体 RL 里常用的算法改进。再看怎么把多轮、长时间的智能体 RL 跑起来。采样和训练怎么分开，怎么异步。

作业 3
07 · 第 13–14 讲

安全与框架：沙箱、攻击与 OpenHands

Agent Safety · OpenHands

智能体能动手以后会出什么事，怎么防。讲沙箱、权限和凭据、提示注入。再看开源智能体框架 OpenHands 是怎么搭的。

讲义
08 · 作业 1–3

作业：Harness、Eval 与 Training

Assignments 1–3

三个公开作业的代码走读。作业 1 从零写一个 ReAct 智能体外壳。作业 2 给智能体设计评测。作业 3 在小框架 ScottyRL 里用 REINFORCE、GRPO 和异步 GRPO 训练智能体。完整复原另见顶栏「复原」。

框架与安全（下）：编排、监控与可观测性

Orchestration · Monitoring

什么时候用固定的工作流，什么时候放手给智能体。用 LangGraph 搭一个带条件路由、检查点、人工审核和重试的客服流程。轨迹多到看不过来时怎么查。第 16 讲按官网给的阅读和前面几讲预写。

10 · 第 17–19 讲（第 17、18 讲只有讲义，第 19 讲预写）

交互：智能体与人的工作、多智能体、人机协作

Future of Work · Interaction

智能体离真正干活还差什么。真实任务怎么收集，环境怎么搭，结果怎么评。几个智能体怎么分工、通信。人和智能体怎么协作。第 19 讲按核验过的论文和前面几讲预写。

课程信息

讲师Daniel Fried、Graham Neubig（卡内基梅隆大学语言技术研究所 LTI）
助教Aditya Soni、Andy Liu、Apurva Gandhi、Demi Wang、Jiarui Liu、Saujas Vaduguru、Weiwei Sun、Yueqi Song

面向训练过神经语言模型的研究生。官网列的先修是 11-667、11-711、10-202，或同等经验。
内容按这个顺序讲。先讲智能体能力：指令遵循、工具调用、规划、记忆。再讲应用领域：通用工具、编程、GUI、社交。然后是训练：SFT、强化学习算法与系统。接着是框架（OpenHands、LangGraph）和安全（沙箱、凭据、对抗攻击）。最后是进阶：人机交互、多智能体、基于搜索的推理。
往期没有往期：2026 秋是第一次开课（第 1 讲开场讲师说"这门新课"）。官网列了内容有重叠的几门 CMU 课。11-711 Advanced NLP（约两周讲 RL 和智能体，更偏 RL 方法）。11-766 Large Language Model Applications（约两周讲工具调用、安全、多智能体、代码助手）。11-891 Neural Code Generation（约两周讲代码生成智能体）。11-777 Multimodal Machine Learning（约一周讲 GUI 智能体）。

怎么用这份笔记

左栏当前这一章的每一讲和每个小节。读完一个小节点它前面的圆圈，读完一讲点 ✓。宽屏点左上角 ☰ 收起左栏，拖它的右边缘调宽度。
难度和重要程度每个小节标题下面有两个标签。难度分易、中、难。易是读一遍就懂。中要停下来跟一遍代码或公式。难要动笔推导。重要程度分三档：★★★ 必须掌握，作业要写或后面要用。★★ 应该看懂。★ 了解即可，跳过不影响后面。这是整理笔记时的判断，不是官方标注。鼠标放到标签上能看到依据。
术语卡片带淡下划线的词是缩写或专有名词。鼠标放上去会弹出小卡片，写着全称和一句解释。手机上点一下就行。
时间戳正文里的 12:34 是这段内容在录像里的位置。点一下，在新标签页里从这里开始播放。
讲义每讲标题条右边的「讲义 lecture-NN」链到官网的 PDF。正文里的「讲义第 N 页」点一下，直接打开那一页。
动画演示可以播放、暂停、单步、回退、调速（0.5× / 1× / 2×）。带代码的演示，右侧逐行高亮代码。控制台输出和变量的变化也跟着显示。
编辑打开章节页右上角的「✎ 编辑」，正文能直接改。改动自动存在本机浏览器里。想把修改写进文件，用 ⋯ 菜单里的「另存为 HTML」。
