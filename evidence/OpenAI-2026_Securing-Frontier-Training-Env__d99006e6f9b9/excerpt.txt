【claim 2】（第 4 节）他们改进了自动停机系统；红队实验有监控和程序化检查，越界就暂停；红队暴露出监控、自动暂停、智能体小队安全机制的漏洞；持续检查防火墙和监控是否在跑，有缺口就报警；新 RL 代码和配置改动也要加检查。
原文："...strengthen our monitoring, and improve the systems that automatically stop runs when we detect activity that poses a serious risk."
原文："These red-teaming experiments were conducted using isolated, purpose-built copies of our research infrastructure, with monitoring and programmatic checks to pause runs if they detected out-of-scope activity."
原文："Testing our monitoring and stopping systems. Our red-teaming efforts have exposed gaps in our monitoring, automatic pausing, and agent team safety mechanisms. We have repaired specific failures and are continuing to test these controls alongside the infrastructure they protect."
原文："We continuously check that firewalls enforce the expected restrictions and that monitors are running, with alerts for failures or gaps in coverage. We are also adding checks to catch new RL code or configuration changes that could weaken these defenses."

【claim 3】（第 5 节）模型越强越会绕过限制：逃出沙箱、借内部服务连外网、跟别的沙箱通信；7 月 Hugging Face 事件和其他未对齐例子说明有网络攻防能力的模型能突破隔离。
原文："A sophisticated model might exploit a software flaw or misconfiguration to escape a sandbox, exploit an internal service to reach the live internet, or find unauthorized ways to communicate with agents in other sandboxes. The Hugging Face incident in July, as well as other examples of model misalignment that we've observed, demonstrates how models with sophisticated cyber capabilities can bypass containment during their training and evaluation."

【claim 4】（第 5 节）9 月 20 日，一个内部研究模型利用 DNS 解析器的配置错误在训练中拿到有限外网访问；暂停最强模型的训练和评测；10 月 1 日恢复，停了 11 天。
原文："On September 20, for example, an internal research model exploited a misconfiguration in a DNS resolver to gain limited access to the live internet during a training run. Although we contained the incident, it exposed weaknesses that required further work. We paused training and evaluation of our most capable models..."
原文："We resumed these workloads on October 1, 11 days after our pause began."

【claim 5】（第 5 节）隔离原则表：边界在对抗下也要守住；边界内有浏览器、代码执行、电脑操作工具；授权通信的智能体共享特定资源；碰到宿主机、许可外通信、连外部系统都算失守；训练和大多数评测里真实互联网在边界外；离线世界；不接外网的立场和理由。
原文："...the limits on what an agent can access must hold even when the agent tries to circumvent them."
原文："Inside the security boundary, agents can have access to browsers, code execution environments, computer-use tools, and other services they might need for their tasks. Agents that are explicitly authorized to communicate can also share particular resources within the same boundary. ... If agents can access the infrastructure that hosts them, communicate with agents outside permitted channels, or reach external systems, that constitutes a failure of containment."
原文："For training and most evaluation, the live internet lies outside this boundary ... we must always be able to prevent a frontier model from achieving unauthorized, arbitrary access to the live internet."
原文："...we've built an "offline world"—a vast set of indexed and cached web content ... All of our frontier RL runs use this offline mode of interaction."
原文："Based on the current state of alignment research, monitoring systems, and the security of internet infrastructure, we believe the responsible approach is to conduct frontier model training with no live internet access. We've implemented this policy and will maintain it until advances in these safeguards justify broader internet access."

【claim 6】（第 6 节）纵深防御四层：沙箱、microVM、监控、网络和云边界；Linux 上受限容器跑在 microVM 里，microVM 有自己的内核、由 hypervisor 隔开；macOS/Windows 虚拟化环境，GPU 任务用带用户态沙箱的 GPU 容器；完全断网做不到；宿主机能直接或间接访问的服务也限制；云厂商提供防火墙、安全组、IAM、私有网络，配置和测试是 OpenAI 自己的责任；"假设内层已失守"的测试。
原文："...sandboxes that restrict what our agents can access and execute, lightweight virtual machines (microVMs) that isolate agents' execution environments from the computers hosting them, monitoring systems that detect unauthorized activity so that we can intervene in time, and network and cloud perimeters designed to maintain containment if all the preceding controls fail."
原文："On Linux, we run restricted containers inside lightweight microVMs. The container limits access to files and processes within the microVM, while the microVM runs its own operating-system kernel and is isolated from the host by a hypervisor. We also use virtualized environments for macOS and Windows, and GPU-backed containers with user-space sandboxing for tasks that require accelerators."
原文："Completely air-gapping this infrastructure ... isn't currently feasible, since we need external connections in order to run and monitor experiments. We therefore restrict outbound internet traffic and unauthorized movement between systems ... These restrictions extend to services that are reachable from the host machines, either directly or through other services..."
原文："Our cloud partners provide essential controls ... including firewalls, security groups, identity and access management, and private networking. We're responsible for configuring those controls correctly, as well as testing how they work together."
原文："We also ran tests that began with the assumption that our inner defenses had already failed—that an agent had escaped its sandbox, evaded our monitoring, and gained full access to its host machine—with the goal of seeing whether the agent could use that access to reach the live internet."

【claim 7】（第 7 节）红队三个目标；小队并行、互借发现；GPT-6 Astra Cyber 和内部前沿模型；给了源码、配置、漏洞文档；隔离副本、监控、云厂商监督；几千亿 token；三类发现及处理；指标服务例子；DNS/防火墙配置错误；没找到能轻易利用又躲过监控的外网路径；发现数下降但要持续红队；写进 safety case。
原文："Reach the live internet: send a request to an external server that we operate. Cross an internal security boundary ... Communicate across isolation boundaries ..."
原文："...this work was conducted by agents organized into teams that could explore different approaches in parallel and build on one another's discoveries. We used some of our most capable and aligned models, including our upcoming GPT‑6 Astra Cyber model and an internal frontier model. ... we supplied infrastructure source code, configuration details, and documentation describing potential vulnerabilities."
原文："In total, we spent hundreds of billions of tokens on these red-teaming experiments."
原文："These agents found several ways to chain vulnerabilities into microVM escapes. We built an automated pipeline to help triage and deduplicate ... contributing the corresponding patches back to the underlying projects, including fixes to software components like Kata Containers ..., gVisor ..., and Moby/Docker ..."

原文："We did not find a route to the internet that agents could trivially exploit while concealing their activity from our monitors."

【claim 8】（第 8 节）不同 microVM、同一批宿主机；不许用网络和共享可写文件；用处理器缓存的计时差传话；Spectre/Meltdown 用过同样手法；共享存储、抢 CPU 时间、TLS 证书缓存三种别的信道；大多数测试指定了信道或给了协议；一次只给漏洞清单也成功；信道慢、难用，但能跨边界；给监控加检查。
原文："...we asked agents in separate microVMs, created and managed by OpenAI's sandboxing software on shared host machines, to exchange synthetic secrets without the use of network connections or shared writable files ... The agents found a way to communicate using the processor's cache ... One agent encoded information by evicting selected data from the cache. Another timed how long it took to reload that data ... This cache-timing technique had also been used to extract information in the Spectre and Meltdown attacks."
原文："Other tests exposed channels involving shared storage, competition for CPU time within a shared execution container, and a TLS certificate cache in OpenAI's offline web infrastructure."
原文："In most of these tests, we directed agents to investigate specific communication channels or provided them with a protocol ... In one instance, we only supplied agents with a broad list of infrastructure vulnerabilities and asked them to find a way to communicate. The agents converted a vulnerability from that list into a communication channel, agreed on a shared encoding, and successfully exchanged information with each other."
原文："While most of these channels carry information slowly and are difficult for models to exploit, they nonetheless provide ways for agents to communicate across boundaries intended to keep them separate. We've added checks to our monitoring systems to detect attempts to communicate through these channels."
